# Рефакторинг и Code Smells

## Проблемы исходного кода
- Длинная функция `process_checkout`
- Магические числа и строки
- Повторяющийся код
- Смешение логики: парсинг, валидация, расчёты

## Применённый рефакторинг
- Вынесены константы: `DEFAULT_CURRENCY`, `TAX_RATE`, `COUPONS`
- Разделены функции:
  - `parse_request`
  - `validate_request`
  - `calculate_subtotal`
  - `calculate_discount`
  - `calculate_tax`
- Основная функция `process_checkout` читается как сценарий сверху вниз
- Все проверки и расчёты теперь вынесены, код проще тестировать

## Результат
- Код стал проще читать, поддерживать и расширять
- Тесты проходят, поведение системы сохранено
